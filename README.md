# エアコン・暖房費計算ツール

エアコンの冷房・暖房にかかる電気代をシミュレーションするWebアプリケーションです。

エアコンの性能、地域の電力会社の料金プラン、利用時間などを入力すると、月々やシーズンごとのおおよその電気代を計算できます。

## デモ

GitHub Pagesで公開しています。

[デモページを開く](https://roflsunriz.github.io/CostCalculator/)

## 使い方

Webブラウザでデモページを開き、設定項目を入力して「計算する」ボタンを押してください。

## 依存更新の自動処理

Dependabot は対象の依存関係を毎週確認します。更新 PR は CI のチェックが成功すると自動で squash merge されます。CI の失敗ジョブは 1 回だけ再実行し、再失敗時は指定した lockfile の再生成を試みます。互換性の問題で CI が通らない更新は手動で修正・検証します。マージ後はデプロイ workflow を起動します。
