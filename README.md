# エアコン・暖房費計算ツール

エアコンの冷房・暖房にかかる電気代をシミュレーションするWebアプリケーションです。

エアコンの性能、地域の電力会社の料金プラン、利用時間などを入力すると、月々やシーズンごとのおおよその電気代を計算できます。

## デモ

GitHub Pagesで公開しています。

[デモページを開く](https://roflsunriz.github.io/CostCalculator/)


## 使い方

Webブラウザでデモページを開き、設定項目を入力して「計算する」ボタンを押してください。

## 依存更新の自動処理

Dependabot は対象の依存関係を毎週確認します。patch／minor 更新は PR のチェック（CI）が成功した後に自動で squash merge されます。CI の失敗ジョブは 1 回だけ再実行します。再失敗時は指定した lockfile を再生成し、CI を再実行します。major 更新は手動で確認します。マージ後はデプロイ workflow を明示起動します。
