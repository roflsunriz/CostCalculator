# エアコン・暖房費計算ツール

## 概要

このプロジェクトは、エアコンの冷房・暖房にかかる電気代をシミュレーションするためのWebアプリケーションです。

お使いのエアコンの性能、お住まいの地域の電力会社の料金プラン、利用時間などを入力することで、月々やシーズンごとのおおよその電気代を簡単に計算できます。

## ✨ デモ (Demo)

このアプリケーションは、以下のGitHub Pagesで公開しており、すぐに試すことができます。

**[デモページへアクセスする](https://roflsunriz.github.io/CostCalculator/)**


## 🛠️ 使い方

Webブラウザで上記のデモページにアクセスするだけで利用できます。
設定項目を入力し、「計算する」ボタンを押してください。
